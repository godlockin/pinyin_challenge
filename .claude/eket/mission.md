# EKET Mission: 拼音识字挑战生成器

## 项目概述
创建一个前端应用，用于生成中文识字挑战练习题（拼音-汉字转换练习），支持多种练习模式和导出打印功能。

## 技术栈决策
- **框架**: React + Vite (适合 Cloudflare Pages 部署)
- **UI**: Tailwind CSS (快速开发)
- **拼音库**: pinyin-pro (支持多音字、声调)
- **PDF导出**: html2canvas + jsPDF 或 react-to-print
- **部署**: Cloudflare Pages (静态站点)

## 功能模块

### 1. 练习模式
- 看拼音写汉字
- 看汉字写拼音
- 多音字选择
- 拼音纠错（找出错误拼音）

### 2. 显示格式
- 田字格（写汉字用）
- 四线三格（写拼音用）
- 横线（简单模式）
- 空白（自由书写）

### 3. 核心功能
- 左右分栏布局（预览 | 输入）
- 实时预览渲染
- 一键导出 PDF
- 调用系统打印
